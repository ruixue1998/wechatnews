# Walkthrough - 结构化 JSON 新闻生成器 (AI 精炼版)

我已经完成了从 RSS (XML) 到 **JSON** 的架构转型。现在，系统能够生成一个结构化、含图片链接且经过 AI 深度二次编辑的 JSON 文件。

## 核心变更

### 1. 新建 `main_json.py`
这是一个全新的数据处理脚本，具有以下特性：
- **精准提取图片**：在抓取阶段，它会自动识别并提取每条新闻的 **第一张图片 URL**，存入 `image_url` 字段。
- **正文纯净化**：提取中文原文的纯文本段落。
- **AI 深度编辑**：
    - 采用分批处理（每 3 条一组）。
    - 提示词要求 AI 扮演“资深编辑”，不再死板翻译，而是**精炼标题、重新排版正文**。
    - 输出格式统一为 **Markdown**。
- **JSON 输出**：生成 `DailyNews_Bilingual.json`。

### 2. 更新 GitHub Action
- 修改了定时任务工作流，使其运行新的 `main_json.py` 并提交 JSON 文件。

## 最终 JSON 数据结构预览

每个新闻对象包含：
- `title_zh`: 原始中文标题
- `content_zh`: 原始中文正文（纯文本）
- `image_url`: 文章配图 URL（若无则为空字符串）
- `title_en`: **AI 精炼后的** 英文标题
- `content_en`: **AI 重排版后的** 英文正文（Markdown 格式）

## 验证与后续
- **验证**：JSON 格式已通过语法检查。
- **使用**：该 JSON 文件非常适合直接对接到你的移动 App、网页前端或自动化工作流中，因为它分离了数据与样式。

> [!TIP]
> 如果你之后需要增加更多的字段（如分类、关键词等），可以在 `main_json.py` 的提取逻辑和 AI Prompt 中轻松扩展。
